## 两个约定

**分页**：单独一行 `---`

```markdown
# 第一页

正文

---

# 第二页
```

**标题**：每页第一个 `#` / `##` / `###` 会进顶部标题栏，正文里不再重复。

::: note
只有标题、内容很少的页面会被当成封面，不显示标题栏。
:::

---

## 章节与目录

**章节**：用 `::: chapter 标题` 单独占一页，后面的页面都归入这一章，标题栏上方会显示章节名。

**目录**：`::: toc` 自动生成章节目录，加 `pages` 会连每页标题一起列出来。

````markdown
::: chapter 一、写 Markdown
分页、标题与基础排版
:::

---

## 目录

::: toc pages
:::
````

## 提示框

::: note
普通备注，灰色。适合补充说明、背景信息。
:::

::: tip
建议和技巧，绿色。适合「这样做更好」。

::: warn
容易踩的坑，橙色。适合「千万别这么写」。

## 代码块

```python
def greet(name: str) -> str:
    return f"hello, {name}"
```

```json
{"name": "Alice", "age": 30}
```

- 按语言自动高亮，支持 python / bash / json / sql 等
- 代码块里的 `---` 不会被当成翻页符

---

## 长代码会自动折行

```bash
curl -X POST https://api.example.com/v1/users \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9.eyJzdWIiOiIxMjM0In0.abc" \
  -d '{"name":"Alice","age":30}'
```

单行超出页面宽度时折行，不会截断。

## 分栏

::: cols
**左栏**

可以放文字、列表、代码块。

- 两栏默认等分
- 两栏内容各自独立排列

|||

**右栏**

```text
app/
├── modules/
└── main.py
```

分栏用来并排展示对照内容。
:::

---

## 分栏可以指定比例

::: cols 1.3fr 1fr
```text
modules/user/
├── router.py
├── service.py
├── repository.py
└── schemas.py
```

|||

`1.3fr 1fr` 表示左栏稍宽。

右边的文字会跟着换行，不会溢出。

::: tip
三栏就写 `::: cols 1fr 1fr 1fr`。
:::
:::

## 图表

```mermaid
flowchart LR
  A[浏览] --> B[校验]
  B --> C[入库]
  C --> D[响应]
```

支持 `flowchart`、`sequenceDiagram`、`stateDiagram` 等。

::: note
建议用 `LR`（从左到右）而不是 `TB`，横向布局在 16:9 画布上更清楚。
:::

## 公式

行内公式 $E = mc^2$，也可以独立成行：

$$
T(n) = 2T\left(\frac{n}{2}\right) + O(n \log n)
$$

由本地 KaTeX 渲染，不需要联网。

## 播放

| 按键 | 作用 |
| --- | --- |
| `←` `→` / 滚轮 | 上一页 / 下一页 |

## 文件与命令

```bash
node server.js              # 打开选择页
node server.js 我的分享      # 直接打开 decks/我的分享.md
```

- 所有幻灯片放在 `decks/`，一份一个 `.md`
- 依赖全部在本地，断网也能完整播放
- 写详细一点：`README.md`
